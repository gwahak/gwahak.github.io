What is complete magic square ?

Not only major diagonals but also minor diagonals sums to 34. 

  A * * *
  * B * *
  * * C *
  * * * D     A + B + C + D = 34
 
  * A * *  
  * * B *  
  * * * C  
  D * * *     A + B + C + D = 34  
 
  * * A *
  * * * B
  C * * *
  * D * *     A + B + C + D = 34
...
...
and so on.

Magic Square of 4 x 4 (880)

Japanese version is availble.

Total 880 magic squares are derived from 220 fundamental set.

For each fundamental matrix , you can derive 4 different magic squares by row-column-exchange rules.

 

Row and column exchange

If you exchange the first column and forth column, and then first row and forth row, you can get different magic square. We call this procedure as 1-4-exchange.
You can define 2-3-exchange by a simillar manner, but the result is the same (rotation or mirror image).
Another rule is so called 1-2-3-4-exchange , in which you exchange the first and second column , third and forth column and then repeat the same exchange rule on the row.

        (D)  <-------------->  (C)
