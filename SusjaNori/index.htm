숫자놀이(Susja Nori)란?

숫자놀이는 정대룡(Jeong Dairyong)이 만든 마법진(magic figure) 사이트로, 마방진(magic square) 이외에도 다양한 마법진에 대한 내용을 다루었습니다.
과거 여러 홈페이지 호스팅 서비스에 올라와 있었으나, 현재는 폐쇄되었습니다.
이 페이지는 원 사이트의 내용을 보존하고, 확인된 오류에 대해서는 별도의 정오표와 수정본을 함께 제공하기 위해 마련되었습니다.

What is Susja Nori?

Susja Nori is a website on magic figures created by Jeong Dairyong. It was formerly hosted on several personal homepage services, but those original sites are now closed. This page is intended to preserve the contents of the original site and, where necessary, to provide separate errata and corrected versions for verified errors.
