Quod

This page collects my Quod-related projects in one place. Two are my own versions. The last one is an archived copyleft implementation by another author.

My versions
  • Quod (2 players) – 2-player version with AI.
  • Quod (2–6 players) – Local multiplayer version (no AI).

Tip: if you are on mobile and the board feels cramped, try landscape mode.

Archived copyleft work
  • JSQuod – A JavaScript implementation of the abstract strategy game Quod, designed by G. Keith Still. Implementation by Jan Bobrowski. (GNU GPL)
